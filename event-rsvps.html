Events

Set up an event here and publish it — it gets its own page on service.wilsonappliance.com/events/… with an RSVP form, and shows on the events listing when marked visible. The roster below each event is the RSVP tracker: add or import invitees, track Planned → Pending → Confirmed, and online RSVPs land on the same list automatically (matched by email, then name). Email guests sends an event email to up to 500 people at a time, each their own copy, with PDFs attached if you like.
