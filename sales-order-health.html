Job status rules used by this report
EverythingNo date in the past (except D7) and no negative COD balance.
D1Written business awaiting deposit or PO — no extra checks.
D2 / D2TShould be ordered. Yellow if COD with no payment received.
D2RYellow by default (product not here, holding schedule time). Red if any COD balance is due or the order isn't routed.
D3Product reserved, ready to fulfill. Yellow if not yet scheduled (no route).
D3-PREObsolete status — always red.
D4 / D4TScheduled to go out. Red if not routed or any COD balance remains.
D7Finished. Red if dated in the future; yellow if still Open ("Not Posted" is fine).
D8Cancelled — yellow until closed.
CPU…Customer pickups — only checked for pickup dates in the past.
