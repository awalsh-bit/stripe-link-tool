Email Signature Builder

Build the standard Wilson signature — your name, job title, and photo, with your phone number(s) and email. The photo is hosted on this site, so it shows up reliably in Outlook and Gmail. Fill in the fields, then copy the signature straight into your email settings.

Preview

This is exactly what recipients will see. The picture loads from the Wilson site — if you replace your photo later, signatures already installed update on their own.

Installing it

Gmail: Settings (gear) → See all settings → General → Signature → Create new → click in the box and paste (Ctrl+V) → Save Changes at the bottom.
Outlook (new / web): Settings → Account → Signatures → New signature → paste into the editor → Save. Set it as the default for new messages and replies.
Outlook (classic desktop): File → Options → Mail → Signatures → New → paste → OK. If pasting loses the picture, use the downloaded .htm file: open it, select all (Ctrl+A), copy, and paste that instead.
