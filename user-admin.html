Team

One profile per person, linked permanently by email — employee code, department, and job title from the directory alongside their login account, page access, and status. A No account flag means the profile needs an invite. Deactivating someone ends their sessions and moves the whole profile to Deactivated users below — nothing is deleted.

Type an existing code to load that person for updating, or click Edit on any row below. Codes are what the payment tools use (update them when systems change, e.g. ePASS → NetSuite).

Job titles & codes

The vocabularies behind the Team editor. Each job title is the relabelable display name for a permanent job code (E10, NE20 — exempt/non-exempt + level) that data links on: rename the title anytime, the code never changes. Titles with web-order alerts on get the green dashboard flag and claim email for every new (or unclaimed) web order. Permission groups are the quick-assign buttons in the permission editor — editing one changes what the button checks going forward, never anyone's saved access.
