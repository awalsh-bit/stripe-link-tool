Team

Every person is one profile with two halves, linked by email: the login account (what they sign in with — status and page access) and the directory entry (their ePASS code, job title, and department — what the sales, commission, and payment tools key on). Someone can have either half alone: No account means a directory person who can't sign in yet; a row with no code means a login that isn't tied to ePASS data. Click any row to see and edit everything about that person in one card.

Job titles & codes

The vocabularies behind the Team editor. Each job title is the relabelable display name for a permanent job code (E10, NE20 — exempt/non-exempt + level) that data links on: rename the title anytime, the code never changes. Titles with web-order alerts on get the green dashboard flag and claim email for every new (or unclaimed) web order. Permission groups are the quick-assign buttons in the permission editor — editing one changes what the button checks going forward, never anyone's saved access.
